gene 問診チェックアプリ README
最終更新：2026-07-22

============================================================
概要
============================================================
このアプリは「大阪 自律神経専門整体院 gene」用の問診チェックPWAです。
患者さまの症状チェック、患者ごとの保存、前回比較、JSONバックアップ、印刷用の総合分析レポート出力に対応しています。

現在の構成では、印刷ボタンを押すとA4レポートが2枚連続で出力されます。

1枚目：院内保管用
・ご紹介カードなし
・右上に「院内保管用」を表示
・院内での記録・管理用

2枚目：患者さま用
・ご紹介カードあり
・患者さまへお渡しする説明用
・ご紹介カードは切り取り式

============================================================
ファイル構成
============================================================
index.html
・アプリ本体のHTMLです。
・PWA設定、画面構造、管理者メニュー、印刷用エリアを含みます。
・style.css と app.js を読み込みます。

style.css
・画面表示と印刷表示のデザインを管理します。
・黒背景×ゴールド基調のアプリUIを定義しています。
・@media print 内でA4印刷専用レイアウトを定義しています。
・紹介カード、院内保管用、患者さま用の印刷レイアウトもこのファイルで調整します。

app.js
・症状チェック、保存、読み込み、JSON入出力、集計、前回比較、印刷レポート生成を管理します。
・12カテゴリ / 82項目のチェック項目を保持しています。
・印刷時の2枚構成もこのファイルで生成します。
・JSON書き出し名は「gene-check-backup_YYYY-MM-DD_HH-MM.json」形式です。

manifest.json
・PWAとしてホーム画面に追加するための設定ファイルです。
・アプリ名、アイコン、テーマカラーなどを管理します。

sw.js
・Service Workerです。
・PWA用キャッシュを管理します。
・更新後に反映されない場合は、このファイル内のCACHE_NAME更新やブラウザキャッシュ削除が必要になる場合があります。

bg.png
・アプリ画面の背景画像です。
・削除すると画面背景の雰囲気が変わります。

logo-full.png
・アプリ背景の透かしロゴ用画像です。
・削除すると画面全体の背景透かしが表示されなくなります。

gene-referral-watermark.png
・ご紹介カード用のgeneロゴ透かし画像です。
・現在は印刷安定性のため、app.js内に画像データを埋め込んだ箇所もありますが、管理用素材として残しています。

line-qr.png
・LINE用QRコード画像です。
・現在は印刷安定性のため、app.js内に画像データを埋め込んだ箇所もありますが、管理用素材として残しています。

icons/icon-192.png
icons/icon-512.png
・PWA用アイコンです。
・ホーム画面追加時に使用されます。

README.txt
・この説明ファイルです。

Thumbs.db / _Thumbs.db / icons/Thumbs.db
・Windowsが自動生成するサムネイルキャッシュです。
・アプリの動作には不要です。
・GitHub上では削除しても問題ありません。

============================================================
管理者メニュー
============================================================
管理者メニューはパスワードで保護されています。

初期パスワード：gene2026

管理者認証後に使用できる項目：
・保存済み患者検索
・保存済み患者一覧
・患者データを保存
・JSON書き出し
・JSON読み込み
・集計を見る
・今回データを削除
・印刷

管理者ロックは約30分で自動的に無効になります。

============================================================
保存とバックアップ
============================================================
通常保存はブラウザ内のlocalStorageに保存されます。
サーバーへ自動送信される仕様ではありません。

端末変更、ブラウザ初期化、キャッシュ削除、端末故障に備えて、定期的にJSON書き出しを行ってください。

JSON書き出しファイル名：
gene-check-backup_YYYY-MM-DD_HH-MM.json

例：
gene-check-backup_2026-07-22_14-30.json

JSONには患者名やチェック内容が含まれるため、取り扱いには注意してください。

============================================================
印刷仕様
============================================================
印刷ボタンを押すと、A4用紙に2枚連続で出力されます。

1枚目：院内保管用
・紹介カードなし
・院内記録用

2枚目：患者さま用
・紹介カードあり
・患者さまへ渡す説明用
・下部に切り取り式のご紹介カードを表示

印刷時の右上「チェック日」は、アプリ上部のチェック日入力欄の日付のみを使用します。
時刻は表示しません。

印刷時の推奨設定：
・用紙サイズ：A4
・倍率：100%
・拡大縮小なし
・余白：標準または既定
・背景グラフィック：必要に応じてON

============================================================
現在の印刷レポート構成
============================================================
① 集計結果
・症状数
・負担スコア
・自律神経負担
・「※低いほど自律神経への負担が少ない目安です。」を表示

② 関連して確認したい項目
・主訴の順位ではなく、チェック内容から関連して確認したい項目を表示

③ 今回の傾向
・チェック項目から自律神経との関連を整理

④ 生活習慣アドバイス
・症状傾向に合わせた生活習慣の確認ポイントを表示

⑤ 砂糖・小麦・乳製品との関連
・食事面で確認したい内容を表示

注意書き：
・本レポートは医療上の診断・治療を行うものではありません。
・強い症状や急な不調がある場合は医療機関へご相談ください。
・施術では、身体の中（内臓・自律神経）と外（筋肉・骨格・筋膜）の両面から状態を確認します。

============================================================
ご紹介カード仕様
============================================================
患者さま用レポートの下部に、ご紹介カードを表示します。
カード部分は切り取って渡せる想定です。

内容：
・ご紹介カード
・大切な方へ
・自律神経の乱れ、睡眠、疲労感、めまい、皮膚症状などでお悩みの方への案内
・ご紹介された方：初回500円OFF
・ご紹介者さま：次回500円OFF
・LINE予約時に「○○さんの紹介です」と伝える案内
・大阪 自律神経専門整体院 gene
・LINE QRコード
・gene-seitai.com

============================================================
アップロード方法
============================================================
GitHub Pagesなどで公開する場合は、gene-check-app-mainフォルダの中身をそのままアップロードしてください。

必要ファイル：
・index.html
・style.css
・app.js
・manifest.json
・sw.js
・bg.png
・logo-full.png
・gene-referral-watermark.png
・line-qr.png
・iconsフォルダ

相対パスで動作する構成のため、ファイル名やフォルダ名を変更しないでください。

============================================================
更新時の注意
============================================================
変更が反映されない場合は、以下を確認してください。

1. index.html内のstyle.css読み込みバージョンが更新されているか
2. sw.js内のCACHE_NAMEが更新されているか
3. ブラウザのキャッシュを削除したか
4. PWAをホーム画面に追加している場合、一度削除して再追加したか
5. GitHub Pagesの反映に数分かかっていないか

============================================================
編集時の注意
============================================================
・app.jsは症状項目、保存、印刷、JSON処理が入っているため、不要な変更は避けてください。
・印刷レイアウトだけを変更する場合は、原則としてstyle.cssの@media printを中心に調整してください。
・管理者操作、JSON読み込み、患者保存に影響する変更は必ず動作確認してください。
・line-qr.pngやgene-referral-watermark.pngは現在の表示に直接使われていない箇所があっても、管理用素材として残してください。
・Thumbs.db類はアプリ動作には不要です。

============================================================
動作確認項目

公開後は以下を確認してください。

・保存済み患者を読み込めるか
・JSONを書き出せるか
・JSONを読み込めるか
・集計結果が表示されるか

・1枚目が院内保管用になっているか
・2枚目にご紹介カードが表示されているか
・右上チェック日に時刻が表示されていないか
・スマホ表示で操作できるか
